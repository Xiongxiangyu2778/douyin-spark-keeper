# 抖音续火花（douyin-spark-keeper）

> 早八自动化系列 · 给抖音私信火花上一道保险

每天自动扫一遍私信列表，**只给还有火花的好友**发一句随机话术，火花再也不会因为"忘了聊"而熄灭。

## 它能干什么

- 🔥 **自动识别火花**：读取会话列表昵称旁的火花徽标（`🔥天数` / `续火花` / `重燃中` / `X天后消失`），没火花的人一个都不碰
- 🗣 **话术库可切换**：内置正式版 / 抽象版 / 温柔版 / 简短版，一行命令切换，也可以自己写
- 🔁 **防重复**：每次随机挑话术，并避开最近 15 条；当天已发过的人自动跳过
- ⭐ **优先级**：重要的人（比如对象）永远第一个发
- ⏰ **计划任务**：每天定时自动运行，启动后还会随机延迟一会儿，避开机械时间点
- 🛡 **会自己恢复**：发过的人会跳到列表顶部、把剩下的人挤下去，脚本会自动往下翻着找；页面被关或卡住会自动重开；每发 8 个人刷新一次列表；连错 6 次直接停下并告诉你谁还没发

## 原理

用 Playwright 驱动 Edge 打开抖音**网页版私信**（`douyin.com/chat`），扫码登录一次后登录态保存在本机，
之后脚本模拟真人操作：滚动会话列表 → 识别火花徽标 → 打开会话 → 逐字输入 → 回车发送。

**不碰第三方协议、不注入外挂、不需要 Root/越狱。** 手机端（安卓 / iOS）什么都不用装，
消息由电脑上的同一个账号发出，手机上自然能看到。

## 快速开始

```text
1. 双击「一键-登录抖音.bat」→ 手机抖音扫码（只需一次）
2. 双击「一键-检查环境.bat」→ 确认能识别到火花好友
3. 双击「一键-选择话术.bat」→ 挑一套话术风格
4. 双击「一键-续火花.bat」→ 立刻续一轮（也可以等计划任务自动跑）
5. 双击「一键-设置每天自动运行.bat」→ 注册每天 21:30 的计划任务
```

## 目录说明

```text
续火花.js        主脚本（--login / --scan / --check / --pick / --force / --dump）
配置.json        所有可调参数（间隔、延迟、优先/排除名单等）
话术/            话术库（当前使用.txt 是脚本实际读取的文件）
一键-*.bat       各种一键入口
run-daily.bat    计划任务专用入口
浏览器数据/      登录态（自动生成，别删）
状态/ 日志/      运行记录与诊断截图（自动生成）
```

## 常用参数（改 `配置.json`，保存即生效）

| 字段 | 默认 | 说明 |
|---|---|---|
| `每人发送间隔秒` | `[4, 7]` | 两个人之间随机等 4~7 秒。18 个火花全程约 3 分钟；若被弹验证码改成 `[12, 20]` |
| `随机延迟分钟` | `2` | 启动后先随机等 0~2 分钟再发，避开整点 |
| `每天最多发几个` | `0` | `0` = 不限（**建议保持 0**，有火花的人少发一个就可能断） |
| `优先这些` | `[]` | 填昵称片段，命中的人排最前面先发 |
| `排除这些` | `[]` | 填昵称片段，命中的人跳过 |

## 注意事项

- **火花规则**：双方每天各发至少一条有效私信才算；纯表情、"嗯"这类敷衍内容可能不算数——所以话术库里都是"带问题、能勾对方回话"的句子
- **电脑要保持开机**：计划任务触发时电脑关机/睡眠就不会跑
- **风控**：脚本走的是网页真人操作路径，且自带随机延迟与随机间隔；但自动化始终有风险，请勿高频群发、勿用于骚扰
- 登录态文件（`浏览器数据/`）等于你的账号，**不要上传或分享给别人**
